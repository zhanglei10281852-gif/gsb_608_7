# Avatar 头像

头像用于展示用户或实体的图像。

## 功能

- 图片、字母、图标类型
- 圆形/方形
- 尺寸预设
- 组合头像
- 在线状态指示器

## Props

| 属性    | 类型                         | 默认值 | 说明                       |
| ------- | ---------------------------- | ------ | -------------------------- |
| src     | `string`                     | -      | 图片地址                   |
| alt     | `string`                     | -      | 图片描述                   |
| name    | `string`                     | -      | 用户名（用于生成字母头像） |
| size    | `xs \| sm \| md \| lg \| xl` | `md`   | 头像尺寸                   |
| rounded | `boolean`                    | `true` | 圆形头像                   |
| online  | `boolean`                    | -      | 在线状态                   |

## 字母头像

当没有提供 `src` 时，会根据 `name` 生成字母头像，取名字的首字母。
